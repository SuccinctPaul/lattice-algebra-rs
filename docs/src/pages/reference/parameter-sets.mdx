# 参数集

方案参数集在代码中表现为**零大小标记类型**，例如：

```rust
pub struct MlDsa65;
impl MlDsaParams for MlDsa65 {
    const K: usize = 6;
    const L: usize = 5;
    const ETA: u32 = 4;
    // ...
}
```

本页汇总参数表，作为方案层实现与 KAT 的对照源。

## ML-DSA（FIPS 204）

公共参数：`q = 8380417`（= 2²³ − 2¹³ + 1），`n = 256`，`d = 13`（t 编码丢弃位），`γ2` 为 `⌊(q−1)/88⌋`（44/87）或 `⌊(q−32)/88⌋`（65）。

| 参数集 | k | l | η | γ₁ | γ₂ | τ | β | ω | c̃ (B) | pk (B) | sig (B) | NIST |

| ML-DSA-44 | 4 | 4 | 2 | 131072 (2¹⁷) | 95232 | 39 | 78 | 80 | 32 | 1312 | 2420 | I |

## ZK / SNARK 参数（设计态）

| 组件 | 环 | 约定 | 状态 |
| --- | --- | --- | --- |
| LaBRADOR 型承诺/批打开 | `R = Z_{2^32}[X]/(X^64 + 1)` | q 为 2 的幂 → 归约为移位；NTT 退化为整数卷积仍可行 | Z2 目标 |
| 挑战空间 | 小环/二进制系数（如 `R_2` 或稀疏 ±1） | 决定提取 slack，进而决定 MSIS 参数 | Z1 定型 |
| 双环嵌入 | `R_q ↪ R_Q`（q 小环承载见证，Q 大 NTT 环承载 sumcheck） | 需要 `Embed` / `ModSwitch` trait（L2/L3 已预留） | Z3 定型 |
| MSIS 安全界 | 由 slack + 声称安全级反推 `k, d, q` | 实现阶段用 lattice-estimator 脚本校准并固化 | 持续 |

> 与 PQC 不同，SNARK 参数尚未被标准冻结；本表随 Z1–Z4 阶段推进滚动更新，**每次变更必须附带 estimator 运行记录**（脚本与输出归档在 `scripts/params/`）。

## 实例化成本提示

const 泛型实例化数量 = 涉及的 `(q, n, k, l, …)` 组合数。策略：

- 基座层仅为参数集白名单实例化（宏批量生成 `impl`，如现有 `matrix_test_macro` 的模式）；
- 测试额外实例化小参数（`Zq<17>`, `n=8`）走同一宏，保证泛型实现不会被白名单特化掩盖 bug。

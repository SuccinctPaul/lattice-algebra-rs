# Parameter Sets

Scheme parameter sets are zero-sized marker types:

```rust
pub struct MlDsa65;
impl MlDsaParams for MlDsa65 {
    const K: usize = 6;
    const L: usize = 5;
    const ETA: u32 = 4;
    /* ... */
}
```

This page is the reference source for implementation and KATs.

## ML-DSA (FIPS 204) — implemented

Shared: `q = 8380417` (= 2²³ − 2¹³ + 1), `n = 256`, `d = 13` (dropped bits of `t`), `β = τ·η`.

| Set | k | l | η | γ₁ | γ₂ | τ | β | ω | c̃ (B) | pk (B) | sig (B) | sk (B) | NIST |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| ML-DSA-44 | 4 | 4 | 2 | 2¹⁷ | 95232 = (q−1)/88 | 39 | 78 | 80 | 32 | 1312 | 2420 | 2560 | I |
| ML-DSA-65 | 6 | 5 | 4 | 2¹⁹ | 261888 = (q−1)/32 | 49 | 196 | 55 | 48 | 1952 | 3309 | 4032 | III |
| ML-DSA-87 | 8 | 7 | 2 | 2¹⁹ | 261888 = (q−1)/32 | 60 | 120 | 75 | 64 | 2592 | 4627 | 4896 | V |

Encoding widths used by the codecs: `t1` packs at `bitlen((q−1)/2^d) − 1` = 10 bits; `t0` at 13 bits; `z` at `bitlen(2γ1 − 1)` = 18/20 bits; `s1/s2` at `bitlen(2η)` = 3/4 bits; `c̃` stored raw.

NTT availability: `q − 1 = 8380416 = 2^13 · 3 · 11 · 31`, 2-adicity = 13 ≥ log₂(2n) = 9 ✅.

## ZK / SNARK parameters (design-stage)

| Component | Ring | Convention | Status |
| --- | --- | --- | --- |
| LaBRADOR-style commitments/openings | `R = Z_{2^32}[X]/(X^64 + 1)` | power-of-two modulus → reduction is a shift | Z2 target |
| Challenge space | small ring / binary coefficients (e.g. `R_2`, sparse ±1) | determines extraction slack, hence MSIS parameters | fixed at Z1 |
| Double-ring embedding | `R_q ↪ R_Q` (small ring for witnesses, NTT-friendly `Q` for sumcheck) | needs `Embed` / `ModSwitch` traits (L2/L3 reserved) | fixed at Z3 |
| MSIS security bounds | derived from slack + claimed level via `k, d, q` | ✅ Core-SVP calibrated (`algebra::security`): binding ≈ 2^4294, Σ soundness 2^225.7 classical | rolling |

> Unlike PQC, SNARK parameters are not frozen by a standard. This table updates as Z1–Z4 progress; **every change ships with an estimator cross-check** via `algebra::security` (archived zone-based runs under `scripts/params/` remain a refinement item).

## Instantiation cost note

const-generic instantiation count = number of `(q, n, k, l, …)` combinations touched. Policy: instantiate whitelisted parameter sets via macros (the `mldsa` module shows the pattern); tests additionally instantiate small parameters (`Zq<17>`, `n = 8`) through the same generic code paths so whitelist specializations cannot hide bugs.

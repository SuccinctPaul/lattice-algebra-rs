# L4 · Serialization

Lattice wire formats are **bit-level**: ML-KEM packs public keys at 12 bits per coefficient, ML-DSA packs `z` at 18/20 bits, `t1` at 10 bits, and so on. `serde`/JSON remain for tests and fixtures only; wire formats live in dedicated packing code with strict validation.

## Current state

- `crypto::bits` — generic little-endian bit packing:
  - `pack_bits` / `unpack_bits`: `bits`-per-coefficient fields into/out of byte strings;
  - `compress_high` / `decompress_high`: coarse quantization (drop low bits) for test-encodings;
- `mldsa::encoding` — FIPS 204 codecs:
  - `SimpleBitPack`/`SimpleBitUnpack` (`t1`, `w1`);
  - `BitPack`/`BitUnpack` with the `(a, b)` centered convention (`s1/s2` at `bitlen(2η)`, `z` at 18/20 bits, `t0` at 13 bits);
  - `HintBitPack`/`HintBitUnpack` — positions plus per-row cumulative counters in a fixed `ω + k` buffer, with malformed-hint rejection (a security check, not cosmetics);
  - `pkEncode`/`pkDecode`, `skEncode`/`skDecode`, `sigEncode`/`sigDecode` built on the above, with length and range validation on every decode.

## Serialization rules

| Use | Mechanism |
| --- | --- |
| unit-test fixtures / JSON | serde (already derived) |
| wire formats / KAT alignment | bit packing per specification |
| internal NTT-domain caches | never serialized (non-canonical representation) |
| canonical trait (`CanonicalSerialize`, ark-serialize style) | 📋 scheduled; blanket impls over `Zq`/`PolyRing`/modules |

## Security requirements

1. **Deserialization is total-check**: reject coefficients `≥ q` (after centered decoding), out-of-range fields, malformed hint buffers, wrong lengths. Decode paths are attack surface.
2. **Roundtrip equivalence**: `decode(encode(x)) == x` property-tested for every codec and parameter combination.
3. **Size assertions**: scheme tests assert exact sizes — ML-DSA signatures 2420 / 3309 / 4627 bytes, public keys 1312 / 1952 / 2592, secret keys 2560 / 4032 / 4896.
4. **Fuzzing** (`cargo fuzz`, scheduled): arbitrary byte streams must never panic decoders.

# L0 · Scalar rings

L0 answers one question: **how to make `Z_q` addition/multiplication correct, fast and generic** — everything upstream stands on these semantics.

## Current state

- `Zq<const MODULUS: u64>` — const-generic ring, value always in `[0, q)`, Barrett-style reduction, extended-Euclidean inverse, `pow`/`square`, serde, byte conversions.
- Capability traits (M0 refactor complete):
  - `Ring` — slim commutative ring; consts `MODULUS`, `ZERO`, `ONE`, `IS_PRIME` (compile-time Miller–Rabin).
  - `Field` — `inverse()`; division (`Div`) is a field operation, so polynomial division requires `R: Field`.
  - `TwoAdicRing` — `TWO_ADICITY` (2-adicity of `q−1`) plus `two_adic_generator(bits)`; the analogue of plonky3's `TwoAdicField`. NTT-friendliness is now expressed in the type system.
  - `CenteredRing` — `centered()` into `(−q/2, q/2]`, `abs_infinity()`, `leq_infinity(b)`; both ML-DSA norm gates and ZK soundness-slack accounting build on these.
- `ring::number_theory` — const Miller–Rabin, primitive roots, prime factorization, modexp (shared by the NTT engine and samplers).

```rust
use lattice_algebra_rs::ring::zq::Zq;
use lattice_algebra_rs::ring::traits::{CenteredRing, TwoAdicRing};

type ZqD = Zq<8380417>;
assert!(ZqD::IS_PRIME);
assert_eq!(ZqD::TWO_ADICITY, 13);            // q − 1 = 2^13 · 1023
assert_eq!(ZqD::new(16).centered(), -16);    // centered representative
assert!(ZqD::new(16).leq_infinity(16));
```

## Reduction strategies

| Strategy | Applies to | Status |
| --- | --- | --- |
| Native 128-bit modulo (Barrett-style) | any `q < 2^32` | ✅ default |
| Barrett with precomputed μ, lazy reduction | small `q` (e.g. 3329) | 📋 ML-KEM hot paths |
| Montgomery | odd `q`, batch work (SNARK parameters) | 📋 |
| Shoup precomputed twiddles | NTT internals | 📋 |
| rustfft generic FFT | non-2-adic `q` (L2 fallback) | ✅ |

Strategy choice is an implementation detail and never enters trait semantics.

## Testing

- Ring axioms over 15 moduli (`ring::axiom_tests`): associativity/commutativity/identity/inverse for add and mul, distributivity, field inverses (prime moduli), 2-adic generator order, centered-ring semantics.
- Cross-checks: Barrett vs naive modulo; `decompose` differential test against the reference bit-trick formulas.

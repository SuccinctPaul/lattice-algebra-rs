# Audit & Gap Analysis

Point-in-time audit of the codebase against the [target architecture](/design/architecture), maintained as the implementation progresses.

## Resolved (M0–M3)

| Item | Resolution |
| --- | --- |
| `Ring` god-trait (mixed in Ord/Display/Div/MatrixElement) | ✅ Split into `Ring` + `Field` + `TwoAdicRing` + `CenteredRing`; `MatrixElement` demoted to the legacy matrix containers' requirement |
| Two parallel NTT implementations (`ntt.rs` runtime version vs `ntt_core.rs` const-generic) | ✅ Legacy `ntt.rs` and `traits.rs` deleted; const-generic engine is the only path |
| Number theory (primitive roots, primality) lived under `ntt` (layering violation) | ✅ Moved to `ring::number_theory`; `ntt::params` re-exports |
| No ring-axiom property tests across moduli | ✅ `ring::axiom_tests`: 15 moduli (2 … 2^32), all axioms + field inverses + 2-adic generator order |
| No module-lattice semantics on the generic containers | ✅ `module` layer: `ModuleVector`/`ModuleMatrix` (+ NTT-domain variants) with type-level dimensions, ExpandA, norms, rounding/hints |
| No sampling, XOF, transcript, bit packing | ✅ `crypto::{xof, sampling, transcript, bits}` |
| No schemes | ✅ `mldsa`: ML-DSA-44/65/87 (FIPS 204) with deterministic + hedged signing, key/sig encodings, size assertions, tamper rejection tests |
| `PolyRing::new` fell back to polynomial division for high-degree inputs | ✅ Replaced by a pure ring-op negacyclic fold (any degree, no `Field` requirement) |
| Dead code (`Barrett` struct, unused test aliases) and clippy warnings | ✅ Removed; `cargo clippy -D warnings` clean |

## Regression rules

- Every migration keeps `cargo test --workspace` green (474 tests); the ring-axiom suite is the safety net for L0 changes.
- The quickstart snippets are guarded by `doc_snippet_check.rs` tests — documentation code cannot rot.
- Shared audit points (norms, centered representatives, decomposition, FS domain separation) are review-mandatory — both PQC and ZK correctness rest on them.

# Quickstart

Runnable examples against the **current** API. Every snippet matches real signatures in `src/`.

## Requirements

- Rust ≥ 1.70 (MSRV)
- Dependencies: `rand 0.9`, `sha3` (SHAKE), `rustfft` (generic FFT fallback), `serde`
- Optional features: `parallel` (rayon)

```toml
[dependencies]
lattice-algebra-rs = "0.1"
```

## Scalar ring `Zq<MODULUS>`

Const-generic modular ring with Barrett-style reduction:

```rust
use lattice_algebra_rs::ring::zq::Zq;
use lattice_algebra_rs::ring::traits::{CenteredRing, Field, TwoAdicRing};

type Zq17 = Zq<17>;   // toy; real schemes use Zq<8380417> etc.

let a = Zq17::new(5);
let c = a + Zq17::new(13);           // 18 mod 17 = 1
let inv = Zq17::new(5).inverse();    // Field: Some(7)
let centered = Zq17::new(16).centered();        // −1  (CenteredRing)
let norm = Zq17::new(16).abs_infinity();        // 1
Zq17::TWO_ADICITY;                              // 4 (TwoAdicRing)
Zq17::IS_PRIME;                                 // true, decided at compile time
```

## Generic polynomials and the quotient ring

`UniPolynomial<R>` is the generic (variable-length) polynomial; `PolyRing<R, N>` is the negacyclic ring `Z_q[X]/(X^N+1)` whose multiplication dispatches to the NTT when available:

```rust
use lattice_algebra_rs::ring::poly_ring::PolyRing;
use lattice_algebra_rs::ring::zq::Zq;
use lattice_algebra_rs::ntt::NttOperatorOptimized;

type Zq17 = Zq<17>;
type R = PolyRing<Zq17, 8>;   // q = 17 ≡ 1 (mod 16) → NTT path

let a = R::from_coefficients(vec![Zq17::new(1), Zq17::new(2)]);
let b = R::from_coefficients(vec![Zq17::new(3), Zq17::new(4)]);
let prod = a.clone() * b.clone();

// x^7 · x = x^8 ≡ −1 (mod X^8+1)
let x7 = R::from_coefficients(vec![0, 0, 0, 0, 0, 0, 0, 1]
    .into_iter().map(Zq17::new).collect());
let x = R::from_coefficients(vec![Zq17::ZERO, Zq17::ONE]);
assert_eq!((x7 * x).coefficients(), vec![-Zq17::ONE]);

// Explicit NTT-domain representation (M1)
let op = NttOperatorOptimized::<Zq17, 8>::new();
let via_ntt = R::from_ntt(a.to_ntt(&op).mul(&b.to_ntt(&op)), &op);
assert_eq!(via_ntt, prod);
```

## Sparse challenges

```rust
use lattice_algebra_rs::poly::sparse::SparsePolynomial;
use lattice_algebra_rs::ring::poly_ring::PolyRing;
use lattice_algebra_rs::ring::zq::Zq;

type R = PolyRing<Zq<17>, 8>;
let c = SparsePolynomial::<Zq<17>>::from_sign_vector(&[1, 0, 0, -1, 0, 0, 0, 0], 8);
let dense = R::from_coefficients(vec![Zq<17>::new(1), Zq<17>::new(2)]);
let _ = c.mul_dense(&dense);   // O(τ·N), no NTT needed
```

## XOF-driven sampling (L4)

All scheme samplers consume a domain-separated XOF stream — determinism is built in:

```rust
use lattice_algebra_rs::crypto::xof::{Shake256Xof, Xof};
use lattice_algebra_rs::crypto::sampling::{BitStream, sample_rej_bounded, sample_in_ball_signs};

let mut xof = Shake256Xof::new(b"my-scheme/sampler");
let mut stream = BitStream::new(&mut xof);
let v = sample_rej_bounded::<Zq<17>>(&mut stream, 2);        // uniform on [−2, 2]
let signs = sample_in_ball_signs(&mut stream, 39, 256);       // τ-sparse ±1 challenge
```

## Module lattices (L3)

```rust
use lattice_algebra_rs::module::{ModuleMatrixNtt, ModuleVector};
use lattice_algebra_rs::crypto::xof::Shake128Xof;
use lattice_algebra_rs::ntt::NttOperatorOptimized;
use lattice_algebra_rs::ring::poly_ring::PolyRing;
use lattice_algebra_rs::ring::zq::Zq;

type Rq = PolyRing<Zq<17>, 8>;
let op = NttOperatorOptimized::<Zq<17>, 8>::new();

// Â derived from a seed, directly in the NTT domain (FIPS 204 ExpandA shape)
let a_hat = ModuleMatrixNtt::<Zq<17>, 2, 2, 8>::expand_from_seed::<Shake128Xof>(&[7u8; 32]);
let v = ModuleVector::<Zq<17>, 2, 8>::zero();
let w = a_hat.mul_vec_ntt(&v.to_ntt(&op)).from_ntt(&op);
assert_eq!(w.infinity_norm(), 0);
```

## ML-DSA (FIPS 204)

```rust
use lattice_algebra_rs::mldsa::mldsa_65 as mldsa;

let seed = [42u8; 32];
let (sk, vk) = mldsa::keygen(&seed);
let sigma = mldsa::sign_deterministic(&sk, b"context", b"hello lattice world");
assert!(mldsa::verify(&vk, b"context", b"hello lattice world", &sigma));
assert_eq!(sigma.len(), 3309);          // ML-DSA-65 signature size
assert_eq!(vk.to_bytes().len(), 1952);  // public key size
```
